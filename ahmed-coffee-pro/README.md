# أحمد كوفي PRO ☕

## التشغيل
1. Node.js نسخة 22.13 أو أحدث (nodejs.org).
2. في الترمنال داخل المجلد:  `node server.js`
3. الموقع: http://localhost:3000  — لوحة الإدارة: http://localhost:3000/admin.html
   (المستخدم `admin` وكلمة السر الافتراضية `ahmedyoussef`)

## الإعدادات (متغيرات بيئة)
| المتغير | الوظيفة |
|---|---|
| ADMIN_PASSWORD | كلمة سر الإدارة (الافتراضية ahmedyoussef — غيّرها قبل النشر الحقيقي) |
| OWNER_WHATSAPP | رقم واتساب صاحب الكافيه (الافتراضي 01055407049) |
| CALLMEBOT_APIKEY | مفتاح CallMeBot المجاني — إشعارات واتساب فقط |
| WA_TOKEN / WA_PHONE_ID / WA_APP_SECRET / WA_VERIFY_TOKEN | واتساب الرسمي (Meta Cloud API) — إشعارات + تحكم بالأوامر |
| NOTIFY_WEBHOOK | رابط Discord/Slack لإشعار فوري بكل طلب/حجز/رسالة |
| DATA_DIR | مكان قاعدة البيانات (حطه على Disk دائم في الاستضافة) |
| NODE_ENV=production | يفعّل Secure cookies (مع HTTPS) |
| TRUST_PROXY=1 | فعّله خلف Render/Railway/Nginx لحساب IP الحقيقي |
| PORT | المنفذ (الاستضافة بتحدده) |

مثال (PowerShell):  `$env:ADMIN_PASSWORD="كلمة-قوية"; node server.js`

## تعديل البيانات
- بيانات الكافيه (موبايل/عنوان/واتساب): أول ملف `public/app.js` (كائن SITE).
- نص "قصتنا": `public/about.html`.
- صور المنتجات: ضعها في `public/img` بأسماء `1.jpg` ... (رقم المنتج).
- الأسعار والتوافر: من لوحة الإدارة > المنيو.

## الاستضافة
ارفعه على Render/Railway/VPS بأمر التشغيل `node server.js`، وفعّل Disk دائم وضع `DATA_DIR` عليه.
(Vercel غير مناسب لأن قاعدة البيانات ملف SQLite.)

## ما يعمله النظام
- قاعدة SQLite حقيقية (طلبات، حجوزات، رسائل، منيو، طاولات).
- ٨ طاولات بأحجام مختلفة، والحجز يختار أنسب طاولة تلقائيًا ويمنع الحجز المزدوج (٩٠ دقيقة لكل حجز).
- دخول إدارة بكلمة سر مشفّرة (scrypt) وجلسة HttpOnly.
- حد أقصى للطلبات من نفس الجهاز، وحماية من XSS وترويسات أمان وCSP.
- إشعار صوتي في اللوحة + Webhook + زر واتساب للرد على العميل.

## واتساب كلوحة تحكم 📲
كل طلب أو حجز أو رسالة جديدة بيوصلك على واتساب برقم 01055407049 بكل بياناته (الاسم، الموبايل، التاريخ، الوقت، الأفراد، الطاولة، الأصناف، الإجمالي، ورابط للرد على العميل).

### الطريقة ١ — سهلة ومجانية (إشعارات فقط)
1. ضيف في جهات اتصال موبايلك رقم CallMeBot (راجع الرقم الحالي من callmebot.com).
2. ابعتله من واتساب رقمك الرسالة:  `I allow callmebot to send me messages`
3. هيرد عليك بمفتاح (APIKEY). حطه في الاستضافة كمتغير `CALLMEBOT_APIKEY` (متشاركوش مع حد).
- الخدمة للاستخدام الشخصي، وبتبعت بس (مفيش استقبال أوامر).

### الطريقة ٢ — واتساب الرسمي (إشعارات + تحكم كامل بالأوامر)
1. أنشئ تطبيق على developers.facebook.com وفعّل منتج WhatsApp.
2. خد `Phone number ID` والـ `Access Token`، وحطهم في `WA_PHONE_ID` و`WA_TOKEN`.
3. حط `WA_APP_SECRET` (من إعدادات التطبيق) و`WA_VERIFY_TOKEN` (أي كلمة تختارها).
4. في إعدادات Webhook ضيف الرابط:  `https://موقعك/api/whatsapp/webhook`  واشترك في `messages`.
5. ملحوظة من Meta: الرسائل الحرة بتوصل في حدود ٢٤ ساعة من آخر رسالة بعتها إنت لرقم الكافيه. ابعت أي رسالة (مثلاً `مساعدة`) مرة كل يوم، أو استخدم قوالب معتمدة.
